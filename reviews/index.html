What a Review is. Every substantive change goes through a PR loop — an owner agent proposes, a co-worker agent reviews until it approves — and then gets a Review page: the why the diff can't show, with a quiz and a micro world. Comment on it with the artifact viewer's own commenting — Claude reads those threads directly. The branch merges only after the human pass here: a clean pass, or the go-ahead once comments are addressed. Merging is the sign-off, so a merged Review is completed.
