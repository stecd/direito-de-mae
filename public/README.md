# public/

Files here are committed to git and can be read by anyone. **Never put anything about a user here.**

- `voice/`: voice notes for the fixed messages (onboarding, deletion, etc.), so ElevenLabs is
  called once per message instead of once per user. Named by a hash of voice ID + exact text, so a
  reworded message simply gets a new clip. Only texts listed in `app.FIXED` are ever written here.
  `import_voice_cache.py` fills it from ElevenLabs history at no cost.

Voice generated by ElevenLabs (elevenlabs.io). The current clips were made on the **free plan**, which
allows non-commercial use with this attribution only. If the project is used commercially, upgrade to a
paid plan, delete `voice/`, and regenerate: audio made on the free plan does not gain commercial rights later.
